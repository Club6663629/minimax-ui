API 服务条款

版本 1.0更新日期 2026-09-30生效日期 2026-09-30
本条款适用于您通过 API KEY 接入本服务（含外部 agent 调用）的情形，是《用户协议》的补充。

一、KEY 的使用

  1. API KEY 仅限申请主体自身在约定范围内使用，不得转售、出租、公开或与他人共享。
  2. 您应妥善保管 KEY；因 KEY 保管不善造成的一切后果由您承担。
  3. 如 KEY 泄露或疑似被滥用，请立即联系我们更换。

二、限流与配额

我们可能根据资源情况对调用频率、并发数与配额进行限制；超限的请求可能被拒绝或排队。

三、禁止用途

不得使用 API 从事违反法律法规的活动，不得伪造他人身份、声音或肖像，不得生成虚假信息，不得用于诈骗等违法用途，不得攻击或干扰本服务及他人。

四、计费

API 调用按相应计价规则计费；余额不足时我们可暂停服务。

五、滥用处理

发现滥用、违规或异常调用的，我们可视情节限制调用、暂停或封禁相关 KEY 与账号。

六、责任限制

API 服务按“现状”提供，我们不对服务不中断、结果准确适用作出担保；因使用 API 产生的后果由您自行承担。

七、变更与终止

本条款更新后将在网站公示；继续调用即视为接受更新后的版本。
